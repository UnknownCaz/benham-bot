Health, logs & cost

Every question about a running Benham has a one-liner answer.

Is it up?

python status.py

Read-only and instant: process/PID, AUTO_REPLY state + allowlist, guilds seen, last login. Touches no Discord, works with the bot down. The tray icon answers the same question at a glance — green = up (see Tray, restart & supervision).

What's it costing?

python usage.py --today     # today's actual consumption
python usage.py --all       # every log, full history

Parsed from the logs the bot already writes — no separate metering. It searches the repo root and logs/, so archived boots still count. Why the bill stays small: the agent's static prefix (the full registry of tool schemas + system prompt, ~7.4k tokens measured pre-Stage-4) is cache-marked, so after the first call each turn reads it at a tenth of the price.
