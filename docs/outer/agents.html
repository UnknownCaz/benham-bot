The agents

Benham is one Discord account, but several different brains answer depending on who's asking and what for. Knowing which one you're talking to explains most surprises.

The three agents (and a half)

agentfilemodelcan reach
Owner agent — the one you talk toagent.pyagent.model in control.json (currently claude-sonnet-5)all 64 capabilities via capabilities.py, web search, and pc_task delegation
Guest agent — what friends getguest.pyguest.model (claude-haiku-4-5)No client tools at all — the API call passes no tools argument. Server-side web search only, plus idea.. filing. A workspace/tool-loop variant existed until 2026-08-16; see archive/guest-tools/.
PC session — the machine itselfcodesession.pythe real Claude Code CLI (your subscription or API key per pc.use_api_key)your actual PC, with your own Claude Code skills loaded — reads free, changes ask first

The PC session is not a reimplementation — it drives the actual Claude Code CLI through the agent SDK with your settings loaded, so "restart Isle of Berk" works because your exaroton skill is there, not because this repo knows what exaroton is.

Which one fires when

triggergoes tonotes
a conversation beat comes duethe tick loop, no modelOne of two autonomous triggers. Every 60s it asks conversations.due() whether an ask needs delivering, nudging or banking, then delivers — it decides nothing, and reaches exactly one outward capability. No model is involved.
a watched Minecraft server changes stateexaroton_watchdog, no modelThe other one, and the more powerful of the two: a tasks.loop started unconditionally at on_ready. It posts alerts to Discord on its own via send_alert, and with auto_stop_empty it calls exa.stop() — an action on a real server with nobody asked. It posts outside the capability chokepoint, straight to channel.send.
you DM Benhamowner agentthe normal path; owner gate checked first
you DM starting pc..PC session directlyskips the agent round-trip entirely
you ask the agent for something PC-shapedowner agent → pc_task → PC sessionblocked in tainted turns; DM-only
you @mention it in a guildowner agentonly in agent_guilds; elsewhere refused
a whitelisted guest DMs itguest agentseparate memory, separate persona, capped daily
anyone else DMs or mentions itnobodyseen and logged, never obeyed
CLI scripts / benham.py dono agent at allstraight through the outbox to capabilities.py — same gates, no model in the loop

That last row matters: the CLI is not an agent. When you run benham.py send yourself, no model decides anything — your command goes through the same policy gates and executes.

Cost profile

agentbillingthe shape of the cost
owner agentAPIthe full registry of tool schemas + system prompt (~7.4k tokens measured pre-Stage-4) per call, but cache-marked — after the first call each turn reads it at a tenth of the price. History is stored as plain text pairs, so long phone conversations don't drag channel dumps along.
guest agentAPI (bills you)haiku + 500 max tokens keeps each message cheap; the caps (100/guest/day, 400 global, 3s cooldown) bound the total. Searched turns count double.
PC sessionpc.use_api_key: currently false = bills the Claude subscriptiona trivial task runs a few cents on API; not free
